## 岗位职责与要求

岗位职责
1、点击监测链路开发：设计并维护广告点击监测接口，接收各投放渠道（OPPO/vivo/小米/荣耀/华为厂商等）的点击回调，解析click_id、设备标识（OAID/IMEI/AndroidID）、IP、UserAgent等关键参数并进⾏持久化存储。
2、归因匹配引擎开发：实现设备匹配核⼼逻辑——App激活上报时，通过OAID/IMEI精确匹配优先，辅以IP+UserAgent+时间窗口（如24⼩时内）的模糊匹配方案，完成点击与激活的关联。
3、转化回传开发：对接OPPO/vivo/华为等厂商渠道的转化API，在⽤户完成注册、关键行为等事件时，按照各渠道规范将转化数据回传给广告平台，支撑oCPA/oCPM模型优化。
4、Marketing API对接与维护：负责各投放渠道Marketing API的接入、调试与日常维护（包括账户管理、报表数据拉取、创意管理等接口），保障投放平台与内部系统的数据同步。
5、数据质量保障与对账：建立点击-激活-转化全链路的监控与对账机制，及时排查归因遗漏、重复回传、数据不一致等问题。
6、渠道变更响应：持续跟踪各渠道API升级、隐私政策变更（如Android 14/15权限变化），快速适配以规避归因失效风险。

任职要求
1、必须具备iaa工具、iaa游戏相关项目经验；2~5年服务端开发经验，有广告归因/用户增长方向经验者优先。
2、技术栈：熟悉 Java（Spring Boot/cloud） ；熟练使用Radis缓存、MySQL数据库，了解Kafka/RocketMQ等消息队列。
3、熟悉广告归因（点击归因、设备匹配、归因窗口期等）；
4、熟悉至少1个主流广告平台（如OPPO、vivo、巨量、腾讯广告等）的转化API/归因规范；
5、数据敏感度：具备数据准确性意识，能通过SQL查询、日志分析快速定位链路中的数据差异问题。
