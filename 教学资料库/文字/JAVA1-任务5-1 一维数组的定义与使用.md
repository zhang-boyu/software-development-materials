# 数组的概述

模块二 
知识链接

数组（Array）是一种引用数据类型，是用于存储相同类型的数据（称为“元素”）的、固定大小的顺序集合。数组由数组名称、数组元素、元素索引和数据类型组成。数组中的每个元素都有一个索引（也可称为下标），数组元素通过索引进行访问，索引从 0 开始逐渐增大。可以用一个统一的数组名和不同的索引来确定数组中唯一的元素。根据数组的维度，可以将其分为一维数组、二维数组和多维数组等。

# 数组的基本特点

模块二 
知识链接

（1）固定长度：数组一旦被创建，其长度就不能改变。
（2）相同类型：数组中的所有元素必须具有相同的数据类型（基本数据类型或对象类型）。
（3）索引访问：数组元素通过索引访问，索引从 0 开始逐渐增大，最大为数组长度减 1。

# 数组的基本特点

知识链接

（4）引用数据类型：数组在 Java 中是引用数据类型，这意味着当开数组时，开发人员实际上在创建一个数组的引用。这个引用指向在堆内存中分配的内存空间，该空间用于存储数组的实际数据。
（5）初始化：在 Java 中，数组必须先初始化才能使用。这可以通过在声明数组时为其分配空间（并可能填充默认值）或使用 new 关键字来完成。

# 数组的声明

（3）数组是一种引用数据类型，因此在使用数组之前，必须确保它已经被初始化（即已经被分配了内存空间）。如果尝试访问未初始化的数组，将会抛出 NullPointerException。
但是，对于基本数据类型的数组，如 int[]，即使未显式初始化，动态初始化也会为其分配内存空间并将其元素的值初始化为默认值，因此不会抛出 NullPointerException。然而，如果声明了一个数组但没有为其分配内存空间（也没有使用 new 关键字），然后尝试访问它，就会抛出 NullPointerException。

# 冒泡排序法

模块二 
知识链接

（1）比较相邻元素：从序列的第一个元素开始，依次比较相邻的两个元素。
（2）交换顺序错误的元素：若前一个元素大于后一个元素（升序排序时），则交换它们的位置。
（3）重复遍历：每轮遍历后，当前未排序部分的最大元素会“冒泡”到序列末尾。
（4）终止条件：当某轮遍历未发生任何交换时，说明序列已完全有序，排序结束。

声明一维数组的基本语法格式为“数据类型 [] 数组名”，其中数据类型可以是Java中任意合法的数据类型，数组名代表数组的名称，该名称必须与后续创建的数组对象同名。

静态初始化是在数组声明时直接对数组元素赋初值，语法格式为“数据类型 [] 数组名 = {初始值列表}”。这种方式适用于已知数组长度和所有元素值的情况，可以简化代码。

动态初始化是在创建数组对象时，通过new操作符分配内存并设置初始值，语法格式为“数据类型 [] 数组名 = new 数据类型[数组长度]”。这种方式适用于未知数组长度或需要在运行时改变数组长度的情况。

使用数组字面量

数组字面量是直接在程序中使用数组的方式，不需要显式声明数组。例如，通过“int[] intArray = {1, 2, 3};”来创建和初始化一个整型数组，这种方式适用于较短的数组和快速开发。

计算一维数组中的最大值

| public class Example02 {
    public static void main(String[] args) {
        // 定义一个int类型的数组，并初始化元素
        int[] arr = {3, 4, 1, 9, 8, 5};
        // 定义一个变量用于记录最大值，初始假设第一个元素为最大值
        int max = arr[0];
        // 遍历数组，从第二个元素开始查找最大值
        for (int i = 1; i < arr.length; i++) {
            // 如果当前元素大于max，则更新max
            if (arr[i] > max) {
                max = arr[i]; // 更新最大值
            }
        }
        // 输出数组中的最大值
        System.out.println("数组arr中的最大值为：" + max);
    }
} |

| public class Example03 {
    public static void main(String[] args) {
        // 初始化一个包含五个整数的数组arr
        int[] arr = {20, 21, 23, 24, 25};
        // 定义一个要插入的新元素num
        int num = 22;
        // 定义一个比arr数组长度大1的新数组arr2
        int[] arr2 = new int[arr.length + 1];
        // 将arr数组的前3个元素复制到arr2数组中
        for (int i = 0; i < 3; i++) {
            arr2[i] = arr[i]; // 将arr中的元素复制到arr2
        }
        // 在arr2的第三个位置插入新元素num
        arr2[2] = num; 
        // 将arr数组的剩余元素复制到arr2中，从索引3开始
        for (int i = 3; i < arr2.length; i++) {
            arr2[i] = arr[i - 1]; // 注意这里的索引调整
        }
        // 输出添加新元素前的arr数组
        System.out.println("添加新元素前的arr数组：");
        // 遍历数组arr并输出每个元素
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + ",");
        }
        System.out.println(""); // 换行
        // 输出添加新元素后的arr2数组
        System.out.println("添加新元素后的arr2数组：");
        // 遍历数组arr2并输出每个元素
        for (int i = 0; i < arr2.length; i++) {
            System.out.print(arr2[i] + ",");
        }
    }

用冒泡排序法实现数组中数据的排序

| public class Example04 {
    public static void main(String[] args) {
        // 初始化一个包含五个整数的数组arr
        int[] arr = {9, 6, 3, 7, 2};
        
        // 排序前，先循环打印数组元素
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + " "); // 打印数组的每个元素
        }
        // 换行作用
        System.out.println();
        // ---冒泡排序法---
        // 外层循环定义需要比较的轮数（两数比较，需要比较n-1轮）
        for (int i = 1; i < arr.length; i++) {
            // 内层循环定义第i轮需要比较的两个数字
            for (int j = 0; j < arr.length - i; j++) {
                // 如果当前元素大于下一个元素，则交换
                if (arr[j] > arr[j + 1]) {
                    // 交换 arr[j] 和 arr[j + 1]
                    int temp = arr[j]; // 临时变量存储当前元素
                    arr[j] = arr[j + 1]; // 将下一个元素赋值给当前元素
                    arr[j + 1] = temp; // 将临时变量的值赋值给下一个元素
                }
            }
        }
        // 排序后，再循环打印数组元素
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + " "); // 打印排序后的数组元素
        }
    }
} |
