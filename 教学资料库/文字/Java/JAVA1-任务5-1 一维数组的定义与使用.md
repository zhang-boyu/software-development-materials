## 第5页幻灯片
数组的概述
模块二 
知识链接
数组（Array）是一种引用数据类型，是用于存储相同类型的数据（称为“元素”）的、固定大小的顺序集合。数组由数组名称、数组元素、元素索引和数据类型组成。数组中的每个元素都有一个索引（也可称为下标），数组元素通过索引进行访问，索引从 0 开始逐渐增大。可以用一个统一的数组名和不同的索引来确定数组中唯一的元素。根据数组的维度，可以将其分为一维数组、二维数组和多维数组等。

数组的声明
模块二 
知识链接
（3）数组是一种引用数据类型，因此在使用数组之前，必须确保它已经被初始化（即已经被分配了内存空间）。如果尝试访问未初始化的数组，将会抛出 NullPointerException。
但是，对于基本数据类型的数组，如 int[]，即使未显式初始化，动态初始化也会为其分配内存空间并将其元素的值初始化为默认值，因此不会抛出 NullPointerException。然而，如果声明了一个数组但没有为其分配内存空间（也没有使用 new 关键字），然后尝试访问它，就会抛出 NullPointerException。

## 第13页幻灯片
冒泡排序法
模块二 
知识链接
（1）比较相邻元素：从序列的第一个元素开始，依次比较相邻的两个元素。
（2）交换顺序错误的元素：若前一个元素大于后一个元素（升序排序时），则交换它们的位置。
（3）重复遍历：每轮遍历后，当前未排序部分的最大元素会“冒泡”到序列末尾。
（4）终止条件：当某轮遍历未发生任何交换时，说明序列已完全有序，排序结束。

## 第14页幻灯片
模块一
基本概念
基本语法格式
静态初始化
动态初始化
声明一维数组的基本语法格式为“数据类型 [] 数组名”，其中数据类型可以是Java中任意合法的数据类型，数组名代表数组的名称，该名称必须与后续创建的数组对象同名。
静态初始化是在数组声明时直接对数组元素赋初值，语法格式为“数据类型 [] 数组名 = {初始值列表}”。这种方式适用于已知数组长度和所有元素值的情况，可以简化代码。
动态初始化是在创建数组对象时，通过new操作符分配内存并设置初始值，语法格式为“数据类型 [] 数组名 = new 数据类型[数组长度]”。这种方式适用于未知数组长度或需要在运行时改变数组长度的情况。
使用数组字面量
数组字面量是直接在程序中使用数组的方式，不需要显式声明数组。例如，通过“int[] intArray = {1, 2, 3};”来创建和初始化一个整型数组，这种方式适用于较短的数组和快速开发。
