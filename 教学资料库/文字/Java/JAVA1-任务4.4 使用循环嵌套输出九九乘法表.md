## 第6页幻灯片
循环嵌套
模块二 
知识链接
在解决某些复杂问题时，若在 for、while 或 do...while 语句的循环体内再包含一条循环结构语句，就形成了循环嵌套。这 3 种循环结构语句之间可相互嵌套，其中较常见的是在for 语句中嵌套 for 语句。在多层循环嵌套中，外层的循环称为外循环，内层的循环称为内循环。
同 if...else 语句的嵌套一样，理论上 Java 支持多层循环嵌套，但从可读性的角度考虑，建议循环嵌套不超过 3 层。
