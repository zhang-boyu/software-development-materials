# 对for语句的说明

模块二 
知识链接

（1）for 语句主要用于按预定的次数执行语句的场合。 
（2）for 语句的执行流程。 
首先执行表达式1，设定循环变量的初始值，也就是循环计数的起点；然后判断表达式2的值为true还是false，进而判断循环是否结束，通常表达式2是关系表达式，当关系表达式的值为 true 时，程序继续进行循环，当关系表达式的值为 false 时，循环结束；最后执行表达式3以控制循环变量的值，表达式3是递增（或递减）表达式，用于控制循环变量的值递增（或递减）。

# 对for语句的说明

模块二 
知识链接

每次循环中循环变量增长（或减少）的值，通常称为循环步长；这样完成一次循环后，重新判断表达式 2 的值为 true 还是 false，直到其值为 false，则结束整个循环。 
表达式 1、表达式 2 和表达式 3 都可以为空（但分号不能省略），三者都为空的时候，相当于构建了一个无限循环。表达式 1 和表达式 3 可以使用逗号语句，来执行多个操作。
逗号语句是用逗号分隔的语句序列。如以下语句： 
for(i=0,j=10;i<j;i++,j--){ 
… 
}

# 对for语句的说明

模块二 
知识链接

（3）如果循环变量在 for 后的圆括号中定义，变量的作用域仅限于循环体内。例如： 
for(int i=0;i<10;i++){ 
… 
} 
System.out.println(i); //超出循环体，非法 
循环体即每次循环要执行的操作，若该循环体只有一条语句，则可以不加花括号，若超过一条语句，则必须用花括号包裹。

# 3种循环结构语句的区别

模块二 
知识链接

总结：
    while 和 for 语句都在循环前判断条件表达式的值，而 do...while 语句至少执行一 次循环体，不管条件表达式的值是否为 true；while 和 do...while 语句适用于循环次数不确 定的场景，for 语句适用于循环次数确定的场景。for 语句是较简洁的，通常是首选循环结 构语句。
