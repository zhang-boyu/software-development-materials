# 12

960网格系统在网页制作中的使用

任务6-10

960网格系统是使用固定宽度960px置中对齐画面的方式呈现在网页上。去除左右两边各10px的空间，留下中间940px的区块以20px作为间隔分栏。 在空间设计上，可随意合并多栏作为版面配置及网页尺寸的设定， 合并出来的栏宽也不会有畸零数，有利于CSS中DIV宽度的设定。

960网格系统常用规格有两种：一个是12栏式的，效果可见图6-10-5，另一个是16栏式的，效果可见图6-10-6。如果你的设计里面分3个区块你就选择12栏式的，那是因为12能被3整除；同理假如你的设计分四个区块，你可以选12栏式或者16栏式，那时因为12和16都可以被4整除。
