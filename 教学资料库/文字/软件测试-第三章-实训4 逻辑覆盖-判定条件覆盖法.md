## 2.1 背景知识

判定条件覆盖是指通过设计足够多的测试用例，使得运行这些测试用例时，判定中的每个条件的所有可能结果至少出现一次，并且每个判定本身的所有可能结果也至少出现一次。

我们看下面的被测试代码：

int a,b;

if(a || b)

执行语句1

else

执行语句2

要达到这段程序的判定条件覆盖,我们采用测试用例:

a为True，b为True；a||b 为True；

a为False，b为False；a||b 为False。

TestCase：①a = True ，b = True；

②a = False，b = False ；
