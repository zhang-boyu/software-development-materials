Java 语言使用“顺序结构”、“选择结构”、“循环结构”这三种基本结构（或由它们派生出来的结构）来实现程序的流程控制。

# 模块二 
知识链接

Java中的三种基本结构

1.顺序结构
顺序结构就是程序从上到下一行一行执行的结构，中间没有判断和跳转，直到程序结束。
2. 选择结构
选择结构提供了一种控制机制，使得程序的执行可以跳过某些语句不执行，转去执行特定选择的语句。
