# 注意事项

模块二 
知识链接

多维数组的维度是固定的，一旦创建，其维度（即数组的“形状”）就不能改变。可以通过 length 属性获取数组的长度，但对于多维数组，length 属性只返回最外层数组的长度。
  要获取内层数组的长度，需要遍历到相应层。
使用多维数组时，务必注意数组的索引不要越界，否则将抛出 ArrayIndexOutOfBoundsException。

| public class Example08 {
    public static void main(String[] args) {
        int[][][] arr = new int[2][2][2]; // 创建一个 2x2x2 的三维数组
        // 外层循环遍历三维数组的第一维
        for (int i = 0; i < arr.length; i++) {
            // 中层循环遍历每个二维数组的第二维
            for (int j = 0; j < arr[i].length; j++) {
                // 内层循环遍历每个一维数组的第三维
                for (int z = 0; z < arr[i][j].length; z++) {
                    // 随机生成 0-9 的整数并赋值给三维数组的当前元素
                    arr[i][j][z] = (int)(Math.random() * 10); 
                }
            }
        }
        // 输出提示信息
        System.out.println("由程序生成的三维数组如下：");
        // 再次遍历三维数组以输出每个元素
        for (int i = 0; i < arr.length; i++) {
            for (int j = 0; j < arr[i].length; j++) {
                for (int z = 0; z < arr[i][j].length; z++) {
                    // 输出三维数组的每个元素及其索引
                    System.out.println("arr[" + i + "][" + j + "][" + z + "]=" + arr[i][j][z]); 
                }
            }
        }
    }
} |
