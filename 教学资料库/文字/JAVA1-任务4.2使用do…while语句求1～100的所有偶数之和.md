# 注意事项

模块二 
知识链接

（1）do...while 语句的语法格式要求，在最后以分号结尾。
（2）do...while 语句与 while 语句的区别。while 语句先判断循环条件是否满足，再决定是否执行循环体。do...while 语句先执行循环体，再判断循环条件是否满足。若首次执行循环，循环条件就不满足，则 while 语句的循环体一次都不被执行，而 do...while 语句的循环体至少被执行了一次。这导致完成同样功能的程序，如果使用不同循环结构语句，则运行结果不同。

使用do-while循环语句求1-100的所有偶数之和

| public class Example02 {
    public static void main(String[] args) {
        int sum = 0, i = 1; // sum变量用来存放偶数的和，i为循环变量，从1开始
        do {
            if (i % 2 == 0) { // 判断i是否为偶数
                sum += i; // 如果是偶数，将其累加到sum中
            }
            i++; // 每次循环，i自增1
        } while (i <= 100); // 当i小于等于100时继续循环
        // 输出1到100之间偶数的和
        System.out.println("1-100偶数之和: " + sum);     }
} |
