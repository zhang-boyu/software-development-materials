# Java 中的跳转语句

模块二 
知识链接

Java 中的跳转语句主要包括以下 3 种：break、continue 和 return（在介绍关于异常的知识点时具体讲解）。
跳转语句的功能是改变程序的执行流程，break 语句可以独立使用，而 continue 语句只能用在循环结构语句的循环体中。

# break语句的语法格式

模块二 
知识链接

break; 
其中，break 是关键字。
break 语句虽然可以独立使用，但通常用于 switch 语句和循环结构语句中，控制程序的执行流程的转移，其使用分为下列 3 种情况。
第一，break 语句用在 switch 语句中，我们已在项目三中遇到过这种情况，其作用是强制退出 switch 语句，执行 switch 语句后面的语句。

# break语句的语法格式

模块二 
知识链接

第二，break 语句用在单层循环结构语句的循环体中，其作用是强制退出循环结构语句。
 例如，以下代码使得 while 语句实际上只输出了 2 次变量 i 的值。
int i=1; 
while (i<=5){ 
 if (i==3){ 
break; 
} 
 System.out.print(" i=" + (i++)); 
 } 
}

# break语句的语法格式

模块二 
知识链接

第三，若程序中有内外两重循环，而 break 语句写在内循环中，则只能退出内循环，进入外循环的下一次循环，而不能退出外循环。要想退出外循环，则需要在外循环中使用break 语句。例如以下代码。
int i, j; 
for (i = 1; i <= 9; i++) { //外循环
if (i > 4) { 
break; 
} 
for (j = 1; j <= i; j++) {//内循环
  System.out.print("*"); 
} 
  System.out.print("\n"); 
}
