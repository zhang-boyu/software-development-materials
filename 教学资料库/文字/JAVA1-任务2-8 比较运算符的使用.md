比较运算符及用法

比较运算符用于对两个数值或变量进行比较，比较运算结果是一个布尔值，即true或false。Java中的比较运算符及用法具体如下表所示。

| 运算符 | 运算 | 范例 | 结果 |
|---|---|---|---|
| == | 等于 | 4 == 3 | false |
| != | 不等于 | 4 != 3 | true |
| < | 小于 | 4 < 3 | false |
| > | 大于 | 4 > 3 | true |
| <= | 小于或等于 | 4 <= 3 | false |
| >= | 大于或等于 | 4 >= 3 | true |
