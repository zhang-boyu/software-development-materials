# 对象的创建与使用

模块二 
知识链接

当我们创建了一个类，就等同于我们创建了一种新的数据类型，你可以像使用基本数据类型一样地使用类。类定义好之后，我们将用该类定义一个实例，即该类的对象。创建一个类的对象通常包括三个步骤，即声明对象、建立对象和初始化对象。

# 对象的创建与使用

模块二 
知识链接

声明对象

声明对象的作用是创建对象空间的管理者，即对象名，也称为对象句柄。例如：
    Student  stu1,stu2 ;
该语句声明了Student类的1个对象句柄stu1,stu2，它们可以被用来引用实际Student类对象的空间，但必须明白此时stu1和stu2只是两个Student类对象的句柄，还没有真正地关联到对象的内存空间。

# 对象的创建与使用

知识链接

建立对象

建立对象，是指用new关键字为对象分配内存空间。在声明对象时，只确定了对象的句柄和它所属的类，并没有为对象分配存储空间，此时对象还不是类的实例。只有通过建立对象这一步，才会为对象分配内存。建立对象的格式如下：
对象句柄 = new 构造方法（[参数列表]）。
例如：
Student stu1;//声明了一个Student类型的对象stu1
stu1=new Student（）;//建立对象并分配内存

# 对象的创建与使用

建立对象

也可以在声明对象的同时建立对象，这称为创建一个对象。创建对象的格式如下：
类名 对象名=new  类名( )；
例如：
Student  stu1=new Student（）;//声明并创建一个Student类型的对象stu1
Student  stu2=new Student（）;//声明并创建一个Student类型的对象stu2

# 对象的创建与使用

模块二 
知识链接

建立对象

创建对象后，可以使用对象访问类中的某个属性或方法，对象属性和方法的访问通过“.”运算符实现，具体格式如下:
对象名称.属性名
对象名称.方法名（）
如给stu1对象的属性name和age赋值：stu1.name=“王华”,stu1.age=18，获取到stu1对象的属性值，然后在控制台输出:System.out.println(stu1.name);System.out.println(stu1.age);
例如：stu1.toString()；调用了stu1对象的toString方法。
