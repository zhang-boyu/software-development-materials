# 传值引用与传址引用

模块二 
知识链接

类属于引用数据类型，引用数据类型就是指内存空间可以同时被多个栈内存引用。在Java程序中，当变量间发生赋值动作时，涉及到传值引用与传址引用的问题。
所谓传值，即指“＝”号两端变量各自具有独立的存放值的内存空间，右端变量把自身的变量值复制给左端变量，这种方式发生在基本数据类型变量间的赋值操作。
所谓传址，即右端变量把自身引用（管理）的内存空间的首地址复制给左端变量，这样“＝”号两端变量共同引用（管理）一个内存空间，这种方式发生在对象变量间的赋值操作及数组间的赋值操作。

# 堆内存和栈内存

模块二 
知识链接

堆内存和栈内存是Java中重要的概念，它们有以下区别：
内存分配方式：
栈（Stack）：由编译器自动分配和释放，存放函数的参数值、局部变量的值等。其操作方式类似于数据结构中的栈。
堆（Heap）：一般由程序员分配和释放，若程序员不释放，程序结束时由操作系统回收。其操作类似于数据结构中的堆。
内存管理方式：
栈：由编译器自动管理，无需手动控制，但容量有限。
堆：需要手动分配和释放，容量大，但容易产生碎片。

# 堆内存和栈内存

模块二 
知识链接

堆内存和栈内存是Java中重要的概念，它们有以下区别：
存储内容：
栈：主要存放局部变量和对象引用，作用域结束后变量消失。
堆：存放所有new出来的对象和数组，可以被多个栈中的变量引用，不使用时需要手动回收。
效率：
栈：效率较高，但存储空间有限。
堆：效率较低，但空间大。
