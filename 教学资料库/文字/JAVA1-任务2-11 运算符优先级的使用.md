# 模块二 
知识链接

复杂的表达式进行运算时，要明确表达式中所有运算符参与运算的先后顺序，通常把这种顺序称作运算符的优先级。运算符的优先级如下表所示。

运算符的优先级

| 优先级 | 运算符 |
|---|---|
| 1 | .  []  () {} |
| 2 | ++  --  ~  !  (数据类型) |
| 3 | *  /  % |
| 4 | +  - |
| 5 | <<  >>  >>> |
| 6 | <  > <=  >= |
| 7 | ==  != |

运算符的优先级

注意：数字越小优先级越高。

| 优先级 | 运算符 |
|---|---|
| 8 | & |
| 9 | ^ |
| 10 | | |
| 11 | && |
| 12 | || |
| 13 | ?: |
| 14 | =  *=  /=  %=  +=  -=  <<=  >>=  >>>=  &=  ^=  |= |
