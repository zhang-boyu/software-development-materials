# 循环结构

模块二 
知识链接

循环结构允许程序多次循环执行相同或相近的任务。在循环结构中，程序会反复执行某个代码块，直到满足某个条件或达到某个特定的执行次数。循环结构通常由循环变量、循环体和循环条件 3 个要素组成。循环变量是一个计数器或标志，用于控制循环的次数或条件。循环体是实际执行的代码块，可以是单个语句或复合语句。循环条件是一个条件表达式，用于控制循环何时停止。

# 循环结构

模块二 
知识链接

当条件表达式的值为 true 时，循环会继续执行；当条件表达式的值为 false 时，循环会停止执行。
Java 中的循环结构提供 while、do...while 和 for 这 3 种循环语句。

# while 语句

模块二 
知识链接

while 的中文含义是“当……的时候”，也就是当条件成立时循环执行对应的代码。例如，要从键盘连续输入 10 位学生的数学成绩。while 语句是循环结构语句中的基本语句，
语法格式比较简单。while 语句的语法格式如下：
while (条件表达式){ 
语句

1 import java.util.Scanner;

5 while(i<=100){ //i 的值从 1 渐增到 100，每次增 1，共循环 100 次
6 sum+=i; //每次循环，sum 都累加当前 i 的值

8 }
