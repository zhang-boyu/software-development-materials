# 4

使用<a>标签实现超链接

任务2-2

<a>标签定义超链接，用于从一个页面链接到另一个页面，其语法结构如下：<a 属性设置>...</a>
其中，属性设置中<a>标签最重要的属性是href属性，它指示链接的目标，链接目标可以是网址，也可以是文件路径，还可以是空（使用“#”表示），href属性必不可少；除此，target属性也是超链接非常重要的属性，属性值可以为：_blank（在新空白窗口中打开链接），_parent（在当前窗口的上一层里打开链接），_self（在当前窗口中打开链接），_top（在顶层框架中打开链接）。

# 15

<iframe>标签使用

任务2-8

<iframe> 标签规定一个内联框架。一个内联框架被用来在当前 HTML 文档中嵌入另一个文档。

所有的主流浏览器都支持<iframe>标签。你可以把提示的文字放到 <iframe> 和 </iframe>里面，这样不支持 <iframe>的浏览器就会出现提示的文字。

例如：
<iframe name="myiframe" id="myrame" src="external_file.html" frameborder="0" align="left" width="200" height="200" scrolling="no">
<p>你的浏览器不支持iframe标签</p>
</iframe>

# 17

使用audio和video标签实现音视频播放

任务2-9

audio标签是一对，其常用属性有：
autoplay：如果出现该属性，则音频在就绪后马上播放。
controls：如果出现该属性，则向用户显示控件，比如播放按钮。
loop：如果出现该属性，则每当音频结束时重新开始播放。
preload：如果出现该属性，则音频在页面加载时进行加载，并预备播放。如果使用 "autoplay"，则忽略该属性。
src：要播放的音频的 URL。
<audio>标签支持的音频格式有：wav，mp3和ogg格式。

任务2-9

video标签也是一对，其常用属性有：

height：设置视频播放器的高度。
width：设置视频播放器的宽度。

# 24

表单格式验证

任务2-12

2、正则表达式<input pattern="regexp">
pattern属性规定用于验证输入字段的模式。pattern属性适用于以下<input>类型：text,search,url,telephone,email以及password。regexp常用表达式如下：
1）^\d+$：正整数+ 0
2）^[0-9]*[1-9][0-9]*$：正整数
3）^((-\d+)|(0+))$：负整数+ 0
4）^-[0-9]*[1-9][0-9]*$：负整数
5）^-?\d+$：整数，正整数和负整数和0：
6）^\d+(\.\d+)?$：正浮点数+ 0
7）^(([0-9]+\.[0-9]*[1-9][0-9]*)|([0-9]*[1-9][0-9]*\.[0-9]+)|([0-9]*[1-9][0-9]*))$：正浮点数
8）^((-\d+(\.\d+)?)|(0+(\.0+)?))$：负浮点数+ 0

表单格式验证

9）^(-(([0-9]+\.[0-9]*[1-9][0-9]*)|([0-9]*[1-9][0-9]*\.[0-9]+)|([0-9]*[1-9][0-9]*)))$：负浮点数 
10）^(-?\d+)(\.\d+)?$：浮点数

13）^[A-Z]+$：由26个英文字母的大写组成的字符串 
14）^[a-z]+$：由26个英文字母的小写组成的字符串 
15）^[A-Za-z0-9]+$：由数字和26个英文字母组成的字符串 
16）^\w+$：由数字、26个英文字母或者下划线组成的字符串 
17）^[\w-]+(\.[\w-]+)*@[\w-]+(\.[\w-]+)+$：email地址
